# 关于本站：数字从哪来，哪些我们故意不给

这不是一本教材，也不是一份行业报告。它是一份**给非程序员的说明书**：解释你手机里那些看不见的步骤在干什么，以及它们各自换了什么。

写它的时候只有一条准则：**能查到的写清楚来源，查不到的明说是查不到。** 下面说这四份底稿怎么分工、标签怎么读。

正文里每一个硬数字，都必须能在其中一份里回得到一行。回不到的，不写。

同一件事有两个都可靠的口径时，站内**分开摆，不取平均**。比如"小数组用插入排序"的阈值，一份源码里是一个数，另一份实现里是另一个数——两个都印、各带出处，绝不合并成一个中间值。这是全站最硬的一条规矩。

## 发现错了怎么说

最有可能出错的地方，是**转引链条太长的那几条**：一篇论文被三份中文资料各自解释一次，最后那个数字常常已经不是原来的意思。站内对这类行的处理是降级成 B 或直接不给。

如果你指出的是这种问题——某个数被换了口径、某个"发明年份"其实是发表年份、某句厂商自报被写成了客观事实——那正是最有价值的反馈。
