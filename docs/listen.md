# 把这本手册当成有声书

地铁到站前五分钟，你把手从口袋里拿出来，发现屏幕上的字太小。于是你把耳机塞上，点了一下页面最底下那个圆形的播放键——然后剩下的事，交给耳朵。

这本手册最初是按"读"设计的，但它真正的使用场景是通勤、洗碗、散步和睡前关灯以后那十分钟。所以每一页都能听，而且听完这一页，它自己会翻到下一页。

## 播放条在哪，长什么样

页面最底部有一条横着的控制条，从左到右是：播放/暂停、上一节、下一节、进度、连播范围、语速、停止。窄屏上它会挤成两行，按钮不消失。

  <div class="mp-stat"><strong>3 档范围</strong><span>本页、本章、全书</span></div>

上面这四个数字里，最值得记住的是最后一个：这本手册是**有顺序的**。侧边栏从上往下就是它建议的读法，连播也照这个顺序走，所以你可以真的把它当一本书听完。

## 三种连播范围，选哪个

::: tip 一句话选择
只想知道今天这一件事 → **本页**。想在通勤路上听完一个主题 → **本章**。打算把这本书听完 → **全书**。
:::

- **本页**：读完这一页就停。适合在工位上偷偷听（不建议，但理解你）。
- **本章**：读完这一页，自动接本章下一页，读完最后一节就停。比如你在听「算法族谱」里的图算法，它会把族谱这一组念完，不会突然跳去讲扫地机。
- **全书**：一路往下走，从「开始」走到「书架」，跨页不停。

范围和语速都会记住。你关掉浏览器再回来，它还是上次那个设置——设置存在本地，不上传任何地方。

## 手机锁屏了还能继续听

播放时系统会拿到一条"正在播放"的媒体信息：标题是这一页的名字，作者是本站，专辑是这本手册。锁屏界面、车机、耳机的播放键都能接管它——暂停、上一节、下一节都对应到连播队列上。

这意味着你可以把手机翻过去扣在桌上，像听播客一样听完一节。

::: warning 听书有几件事做不到，别怪它
它读的是**浏览器的系统语音**，不同设备、不同系统音色差别很大；它读不了图——所有图表在朗读时会被整块跳过，所以每张图最该记住的那句话，正文里都会用人话再说一遍；它也不会在你打断你之后自动接上，遇到需要看数字的段落，还是得点开眼睛。
:::

## 为什么图表会被跳过

这本手册的图是给人眼看的：曲线、格子、柱状。把它们逐条念出来只会变成"横轴 10 纵轴 3 横轴 20 纵轴 7"这种灾难。

所以规则是：**图读数，正文讲人话。** 每张图下面都跟着一句结论，正文里还会把关键数字用完整句子再说一次。你听到的那句，就是这一页真正要你带走的东西。

<div class="mp-quote">听书不是把字变成声音，是把"该记住的那句"变成声音。</div>

## 听完一本，大概要多久

按每页 1 到 2 分钟估算，全书 42 页大约需要**一小时上下**——每天通勤两趟、每趟听本章，一周能听完。这是估算，不是承诺：有人听得快，有人会在「复杂度」那一页反复听三遍。
